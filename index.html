MY JOURNEY

Learning & Progress 🌷

A look at what I learned and how my technical skills developed throughout the program.

🌸

Identify My Learning

Topics that stood out to me

The topics that stood out to me the most were Python, GitHub, HTML, and CSS. Python was one of my favorites because the Codédex activities were fun and engaging, which made learning the different concepts easier than I expected. GitHub also became pretty easy to navigate after I explored it a few times, and I learned how to manage and publish my projects. HTML and CSS helped me understand how websites are structured and designed. I especially enjoyed seeing how small changes in the code could completely change the appearance of a webpage.

🌷

My Progress

How I've grown throughout the program

When I started Tech Teen Launchpad, I only knew the basic concepts of coding and didn't have much experience using these different tools. At first, HTML and CSS looked confusing because I didn't understand how all the tags, classes, and different sections connected. As I practiced, I learned how the code was organized and became much better at reading and understanding it. I also gained more experience with Python, GitHub, JavaScript, HTML, and CSS. One of my biggest improvements was becoming more comfortable troubleshooting problems and trying different solutions when something in my code didn't work.
